05 / FIREBASE-EINRICHTUNG

  1. Öffne console.firebase.google.com und erstelle ein Projekt.
  2. Erstelle eine Web-App und eine Realtime Database.
  3. Aktiviere Authentication mit einem passenden Anmeldeverfahren.
  4. Verwende sichere Datenbankregeln; niemals eine offene Datenbank für alle Schreibzugriffe veröffentlichen.
  5. Für öffentliche Matches muss ein vertrauenswürdiger Server Räume reservieren, Spielerzahl prüfen und den Countdown verbindlich starten.
